# AI Project Rules

Before making changes, read:
- docs/CLIENT_BRIEF.md
- docs/PROJECT_SPEC.md
- docs/ARCHITECTURE.md
- docs/DESIGN_SYSTEM.md
- docs/TODO.md

Rules:
- Do not invent features not present in the spec.
- Keep changes scoped to the requested task.
- Avoid unnecessary dependencies.
- Respect acceptance criteria.
- Run lint, typecheck, test and build before considering work complete.
- Update documentation when architecture or product decisions change.
- Do not merge without review and successful checks.
