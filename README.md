# AI Web Pipeline Template

Template operativo per sviluppare siti e web app con una pipeline AI → GitHub → CI → review → deploy opzionale.

## Flusso

1. Questionario cliente
2. CLIENT_BRIEF
3. PROJECT_SPEC
4. ARCHITECTURE
5. Scaffold progetto
6. Sviluppo feature-by-feature
7. Lint, typecheck, test e build
8. Commit e push su branch
9. Pull request
10. Review
11. Merge su main
12. Deploy opzionale

Vercel non è configurato di default.
