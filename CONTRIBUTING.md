# Contributing

## Branches

- `feature/<name>`
- `fix/<name>`
- `refactor/<name>`

## Workflow

1. Read the project docs.
2. Create a scoped branch.
3. Implement one feature or fix.
4. Run `npm run check`.
5. Commit with a clear message.
6. Push and open a pull request.
7. Review functionality and visuals.
8. Merge only after checks pass.

## Commit examples

- `feat: add contact form`
- `fix: validate email input`
- `docs: update architecture`
- `refactor: simplify navigation`
